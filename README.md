# FisioGest - Gestión de Pacientes

## Descripción

FisioGest es un sistema desarrollado para apoyar la gestión de un consultorio de fisioterapia. Para la Unidad 3 se trabajará en el módulo de Gestión de Pacientes.

Este módulo permitirá registrar y administrar información básica de los pacientes mediante una aplicación web.

## Módulo implementado

**Gestión de Pacientes**

El módulo permite ingresar los siguientes datos:

- Cédula
- Nombres
- Apellidos
- Teléfono
- Dirección
- Correo electrónico

## Flujo de trabajo

Para organizar el desarrollo se utilizará una rama principal llamada `main`, donde se mantendrá el código estable.

Los cambios se realizarán en ramas de trabajo, por ejemplo:

`feature/gestion-pacientes`

Una vez realizados y revisados los cambios, se utilizará un Pull Request para unir la rama de trabajo con `main`.
